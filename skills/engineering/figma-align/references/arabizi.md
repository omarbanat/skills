# Reading design feedback in Lebanese Arabizi

Arabizi is Lebanese Arabic written in Latin letters. The digits stand for sounds: 3 = ع, 7 = ح, 2 = ء, 8 = ق, 5 = خ. Feedback usually comes as a pasted list, often mixed with English or French words for the UI parts.

Write each checklist item in English. If a line is ambiguous, keep your reading in the checklist so the user can correct it.

| Arabizi | Meaning |
|---|---|
| ma mechye / mesh mechye | doesn't work |
| zedet | I added |
| mana mtl / mesh metel | isn't like / doesn't match |
| manon sah | they aren't right |
| manon consistent | they aren't consistent |
| ba3da el adime | still the old one |
| mana updated | isn't updated |
| bi8ati | covers / hides |
| ma ydal | shouldn't stay |
| lezem ykoun / lezem ykounou | it must be / they must be |
| kamen | also |
| sar tahet | it moved down |
| fo2 | up / above |
| no need la… | … isn't needed |
| 3meltelak fia screen | I made you a screen for it (a new Figma frame exists, so look for it) |
| iza | if / when |
| fia / fiya | in it |
| fi menon | some of them |
| (see image) | points to a screenshot that usually didn't come through |

Example, from an October 2026 round:

- *"iza ma 3amel scroll el date picker bi8ati el button"*: when you scroll, the date picker covers the button. The picker must follow its trigger on scroll.
- *"no need lal search bl top navbar, sar tahet ma3 el filters"*: no search in the top navbar; it moved down next to the filters.
